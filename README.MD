# Repository Overview
This repository contains two distinct projects:

### 1. Distributed Transformer Pretraining (`Distributed Transformer Pretraining/`)
An optimized, multi-GPU PyTorch pretraining pipeline featuring:

- Distributed Training: Fully Sharded Data Parallel (FSDP)

- Architecture Enhancements: SwiGLU activation functions and Warmup-Stable-Decay (WSD) learning rate scheduling.

- Scaling & Automation: Chinchilla scaling laws grid search executed via Slurm job arrays.

### 2. RAG Visual QA (`RAG visual QA/`)
A group project exploring a multi-agent system for visual question answering using computer vision, LLMs, and Retrieval-Augmented Generation (RAG).
